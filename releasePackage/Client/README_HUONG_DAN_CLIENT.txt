======================================================================
         HƯỚNG DẪN CÀI ĐẶT VÀ SỬ DỤNG MÁY TRẠM (CLIENT)
======================================================================

1. YÊU CẦU HỆ THỐNG:
- Hệ điều hành: Windows 10 / 11 (64-bit).
- Kết nối cùng mạng LAN (mạng nội bộ) với Máy Chủ (Server).

2. CÁC BƯỚC THỰC HIỆN TRÊN MỖI MÁY TRẠM:
Bước 1: Chép toàn bộ thư mục "Client" này vào máy trạm (ví dụ: ổ D:\Client hoặc C:\Client).

Bước 2: Chạy file "1-Cau-Hinh-IP-May-Chu.bat"
        -> Nhập địa chỉ IP của Máy Chủ (ví dụ: 192.168.1.100).
        -> Chương trình sẽ tự động lưu cấu hình.

Bước 3: Chạy file "2-Chay-Client.bat"
        -> Ứng dụng Client Agent sẽ khởi chạy và kết nối tới máy chủ.
        -> Máy chủ sẽ tự động nhận diện máy trạm theo tên máy tính.

Bước 4 (Tùy chọn): Chạy file "3-Tu-Dong-Khoi-Dong-Cung-Windows.bat"
        -> Chọn phím 1 để máy trạm tự động khởi chạy phần mềm mỗi khi bật máy.
